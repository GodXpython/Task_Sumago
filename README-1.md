# Test — Libraries, ML, SQL

Solution for the assignment: NumPy, Pandas, Matplotlib & Seaborn, EDA, Machine Learning, SQL.

## Files
- `assignment_solution.py` — full solution, all 6 questions, runs end-to-end
- `employees.csv` — dataset used
- `employees_modified.csv` — output of Question 2 (with calculated column)
- `best_model.pkl` — best ML model saved with joblib (Question 5)
- `plots/` — all 5 visualizations (Question 3)
- `run_log.txt` — full console output from running the script

## How to run
```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib
python assignment_solution.py
```

## How to upload this to GitHub (step by step)

1. Go to https://github.com and log in (create a free account if you don't have one).
2. Click the **+** icon (top right) → **New repository**.
3. Name it something like `libraries-ml-sql-test`, keep it **Public**, then click **Create repository**.
4. On the new repo page, click **uploading an existing file** (or drag-and-drop).
5. Drag in all the files from this folder (`assignment_solution.py`, `employees.csv`, `employees_modified.csv`, `best_model.pkl`, `README.md`, and the `plots` folder).
6. Scroll down, click **Commit changes**.
7. Once uploaded, click the green **Code** button → copy the **HTTPS** link, OR just copy the browser URL of the repo (e.g. `https://github.com/yourusername/libraries-ml-sql-test`) — that's the link to paste into the submission's "Submission Link" field.
8. Make sure the repo is set to **Public** (Settings → General → Danger Zone) so it's viewable by the trainer.
