# Test — Libraries, ML, SQL

Solution for the assignment: NumPy, Pandas, Matplotlib & Seaborn, EDA, Machine Learning, SQL.

## Files
- `assignment_solution.py` — full solution, all 6 questions, runs end-to-end
- `employees.csv` — dataset used

## How to run

```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib
python assignment_solution.py
```
